

### 📁 Copy Windows Project to WSL and Open in VS Code

```bash
# ✅ Use PowerShell to copy project from Windows to WSL
wsl cp -r /mnt/c/Users/ad/Documents/selenium-headless-mode-demo ~/
```

---

### 📂 Open Project in WSL Terminal

```bash
# ✅ Launch WSL shell
wsl

# ✅ Go to the copied project directory
cd ~/selenium-headless-mode-demo
```

---

### 📝 Open in VS Code (WSL)

```bash
# ✅ Open project in VS Code from within WSL
code .
```

> 💡 Make sure you have the **"Remote - WSL"** extension installed in VS Code.
